# منصة مستر حازم للكيمياء 🧪

## طريقة الرفع على Vercel (مجاني)

### الخطوة 1 — ارفع المشروع على GitHub
1. روح على [github.com](https://github.com) واعمل حساب مجاني
2. اضغط **New Repository** وسميه `hazem-chemistry`
3. ارفع كل ملفات المجلد ده

### الخطوة 2 — اربطه بـ Vercel
1. روح على [vercel.com](https://vercel.com) واعمل حساب بـ GitHub
2. اضغط **Add New Project**
3. اختار repository `hazem-chemistry`
4. اضغط **Deploy** — خلاص!

### الخطوة 3 — الموقع أونلاين ✅
هتاخد لينك زي `hazem-chemistry.vercel.app` تقدر تبعته للطلاب فوراً
